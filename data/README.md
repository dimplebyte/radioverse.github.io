# RadioVerse Data

This folder contains the structured data used by the RadioVerse application.

## Files

### stations.json
Contains radio station information such as:
- Station name
- City
- Country
- Coordinates
- Language
- Genre

### countries.json
Contains country information used for geographical navigation and station discovery.

### india-states.json
Contains Indian state information and state capitals.

### rajasthan-districts.json
Contains Rajasthan district information for detailed regional exploration.

### quotes.json
Contains short quotes displayed throughout the RadioVerse experience.

## Data Structure

All files in this directory use JSON format so that the JavaScript application can easily load and process the data.

## Future Integration

The station data can later be connected with a live radio station API to provide a larger and continuously updated collection of radio stations.
